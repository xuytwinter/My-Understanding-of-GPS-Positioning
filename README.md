# My Understanding of GPS Positioning

**Author:** Yuntao Xu (许云涛)  
**Student ID:** 26109261g  
**Course:** LSGI533

The reports cover GPS observation equations (pseudorange, carrier phase and Doppler), GPS orbit coordinate computation and satellite clock error algorithms, and receiver positioning algorithms using pseudorange measurements.

The PDF versions were converted from these Markdown sources. Download or clone this repository with its assets directory to open the reports in Typora; keep the relative image paths intact and enable inline math support for LaTeX expressions. GitHub previews may display some LaTeX delimiters as source text.

Lecture-slide screenshots are reproduced from the LSGI533 teaching materials for reference. Captions identify the lecture and PDF page; the teaching materials remain the work of their original authors. The explanatory text and tutorial expansions are distinguished from the screenshots in the reports.
